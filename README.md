# ⏰ Time Wizard 🃏 - Yu-Gi-Oh! Inspired Time Tracking

## 🌟 Duel Your Productivity Like a True Duelist!

Inspired by the time-bending monster card of Yu-Gi-Oh!, **Time Wizard** is a playful time tracking application!

### 🔮 Features

- **Time Summoning**: Add time spent on tasks
- **Task Tracking**: Keep a log of your time 
- **Edit & Delete**: Control your time realm with easy management

### 🛠 Technologies Used

- **Frontend**: 
  - HTML5
  - CSS3 (with Bootstrap)
  - Vanilla JavaScript
- **Storage**: 
  - Local Storage
- **Design Inspiration**: 
  - Yu-Gi-Oh! Anime Aesthetics
  - Responsive Bootstrap Layout

### 🎴 Usage

1. **Enter Time**: Enter minutes spent on a task
2. **Track Logs**: View your time logs in the magical table
3. **Edit Entries**: Modify or delete time entries as needed

### 🌈 Styling

Featuring a dark theme reminiscent of a mystical dueling arena, with UI elements inspired by Yu-Gi-Oh! card designs.

### 🚀 Getting Started

1. Clone the repository
2. Open `index.html` in your browser
3. Start tracking your time like a true Time Wizard!
